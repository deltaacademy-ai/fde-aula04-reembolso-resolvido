# Política de reembolso v1 (fictícia)

Esta política é inventada para a aula. Não descreve nenhuma empresa real.

## Regras

1. Reembolso só para pedido entregue há no máximo 30 dias. Conta-se a partir da data de entrega; 30 dias exatos ainda estão dentro do prazo.
2. Um reembolso por pedido. Se o pedido já tem reembolso, um novo pedido é duplicidade e deve ser negado.
3. O valor do reembolso nunca é maior que o valor do pedido. Se o cliente pedir mais, reembolsa-se no máximo o valor do pedido. Se o cliente não disser um valor, considera-se o valor total do pedido.
4. Pedido cancelado antes da entrega não tem reembolso: o estorno já foi feito no cancelamento.
5. Reembolso de até R$ 500,00 (inclusive) gera uma proposta que vai para aprovação humana.
6. Reembolso acima de R$ 500,00 é encaminhado ao financeiro. Nesse caso não se gera proposta.
7. Toda proposta exige aprovação humana antes de ser executada. Nenhum agente executa reembolso por conta própria.
